## Place Intelligence Requirements
Each place must expose:
- canonical place name
- current location
- historical place names
- coordinates
- coordinate status
- confidence
- jurisdiction
- tribal territory overlap
- related life events
- related people
- historical context
- machine intelligence summary
- sources

## Coordinate Rules
Coordinates must be marked as:
- verified
- approximate
- tribal territory
- unknown

Unknown coordinates must not be silently invented.
