• Recursive FAMC chain — All ancestors by generation

🖼️ PROFILE PHOTO TAGS (GEDCOM MEDIA REFS)

Ancestry does not export actual image files, only references.
These are the only valid GEDCOM tags for photos:

• OBJE — Media object container
• FILE — Path or filename
• FORM — File type (jpg, png, etc.)
• TITL — Title/caption


Example Snippet

1 OBJE
2 FILE media/123456789.jpg
2 FORM jpg
2 TITL Profile Photo


What your engine must do

• Store the reference (FILE)
• Store the type (FORM)
• Store the caption (TITL)
• Allow user to upload or link the actual photo later
